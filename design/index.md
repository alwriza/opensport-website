# Components

- [Button](components/Button.md) — кнопка действия, 6 рабочих вариантов, 4 размера
- [Input](components/Input.md) — однострочное текстовое поле
- [Card](components/Card.md) — контейнер с 5 составными частями (Header/Title/Description/Content/Footer)
- [ProgressBar](components/ProgressBar.md) — горизонтальный индикатор прогресса 0–100
- [Badge](components/Badge.md) — маленькая пилюля-ярлык, 4 варианта
- [Avatar](components/Avatar.md) — круглый аватар с фолбэком-инициалом
- [ListItem](components/ListItem.md) — строка списка (аватар + текст + trailing), паттерн из таблицы рейтинга
- [EmptyState](components/EmptyState.md) — заглушка пустого раздела, паттерн из дашборда игрока
- [Chart](components/Chart.md) — радар-диаграмма навыков (требует замены библиотеки на RN, см. gaps.md)

Нет в вебе, не создано: ErrorState — см. [gaps.md](gaps.md).
