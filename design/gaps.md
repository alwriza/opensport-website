# Gaps

Чего нет в вебе, но нужно мобильному приложению.

## Компоненты

- **ErrorState** — нет ни компонента, ни повторяющегося паттерна в вебе
  (только точечные `toast`-уведомления об ошибках). Нужно спроектировать
  с нуля: иконка ошибки, заголовок, описание, кнопка retry.
- **Chart на React Native** — веб использует `recharts` (SVG DOM API),
  несовместим с RN. Нужна замена библиотеки при сохранении визуального
  контракта из `components/Chart.md`.
- **Input — состояние ошибки** — в вебе нет реализации (нет красной рамки
  / текста ошибки под полем формы).
- **Button — состояние loading** — в вебе не реализовано (нет спиннера
  внутри кнопки).

## Не входит в веб-приложение вовсе

- иконка приложения (app icon, все размеры iOS/Android)
- splash screen
- иконки таб-бара (нижняя навигация — в вебе используется верхний navbar/sidebar, паттерна таб-бара нет)
- тексты запроса разрешений (камера — для загрузки видео анализа, галерея, уведомления)
- deep link / share preview изображения

## Токены с неоднозначным статусом

- Классы `primary-glow`, `shadow-card`, `hover-lift`, `bg-gradient-premium`,
  `shadow-premium`, `shadow-hero`, `glass-card` используются в
  `button.tsx` / `card.tsx`, но не определены ни в `tailwind.config.ts`,
  ни в `src/index.css` — в текущей сборке не резолвятся ни в какое
  значение. Не перенесены в tokens.ts. Если эти варианты действительно
  нужны в UI — сначала нужно восстановить их определения в вебе.
